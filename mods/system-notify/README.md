# system-notify

에이전트가 사용자 입력을 기다리거나 작업을 마쳤는데 Herdr 창이 비활성이면 macOS 알림을 띄웁니다. 화면에는 아무것도 그리지 않습니다.

## 무엇을 하나

- 레이아웃의 0px 크기 `system-notify` 블록으로 살아 있기만 합니다(메인 창 레이아웃에만 있고, 두 번째 창에는 없습니다).
- 1초마다, 그리고 render 때마다 에이전트 상태를 이전 스냅샷과 비교합니다. 시작 시점의 상태는 알리지 않고 이후 바뀐 것만 알립니다.
- 상태가 `blocked`(`입력이 필요합니다 (Needs you)`) 또는 `done`(`작업을 마쳤습니다`)으로 바뀌었고 Herdr 창이 비활성일 때만 알립니다. 창이 활성이면 알리지 않습니다.
- 알림 제목은 `<프로그램 이름> · <메시지>`, 부제는 `<space> › <탭>`, 본문은 에이전트 제목입니다. 알림 ID는 에이전트당 1개(같으면 교체), 알림센터 묶음은 space 단위입니다.
- 알림을 클릭하면 헬퍼가 `herdr-app do agent.focus`로 그 에이전트에 포커스하고 Herdr를 앞으로 가져옵니다.
- 창이 가려지거나 디스플레이가 꺼져 render가 불리지 않아도 상태를 놓치지 않도록 타이머로도 확인합니다.

## 원본

herdr 내장 mod의 복제본이 아니라 이 저장소에서 새로 작성한 mod입니다.

## 의존

- [extensions/notify-helper](../../extensions/notify-helper/README.md): 알림을 실제로 올리는 `herdr-notify.app`이 `~/.local/share/herdr-notify/`에 설치돼 있어야 합니다. 없으면 알림이 뜨지 않고 로그만 남습니다.
- 클릭 시 포커스 이동에 `~/.local/bin/herdr-app`을 씁니다.
