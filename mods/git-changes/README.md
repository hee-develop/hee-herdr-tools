# git-changes

Git 변경 파일 목록과 diff를 보여 주고, 커밋과 Discard를 할 수 있는 패널입니다.

## 무엇을 하나

- 레이아웃의 옆 패널(`panel-body`) 안 `changes` 블록으로 뜹니다. 포커스된 pane(없으면 활성 space)의 폴더가 속한 git 저장소를 보여 줍니다. 원격 머신의 space도 그 머신에서 git을 실행해 보여 줍니다.
- 헤더에 파일 수, 선택 수, 전체 추가·삭제 줄 수를 보여 주고, 목록에는 파일마다 상태 문자(M, A, D, U 등)와 경로, 추가·삭제 줄 수를 보여 줍니다. 1,000개를 넘으면 앞의 1,000개만 보여 줍니다.
- 아래쪽 영역에 diff가 뜹니다. 처음에는 첫 파일의 diff를 보여 주고, 다른 파일을 고르면 바뀝니다. 새 파일은 내용을 `+` 줄로 보여 줍니다.
- 커밋 메시지 입력란과 `Commit` 버튼: `git add -A` 후 `git commit -m <메시지>`를 실행합니다.
- 10초마다, 그리고 로컬 폴더는 파일 변경을 감시해서 다시 읽습니다. 읽을 때 `.git`에 쓰지 않는 옵션을 씁니다.

## 조작

- 행 클릭: 그 행만 선택하고 diff를 열고 닫습니다.
- Cmd+클릭: 선택에 더하거나 뺍니다. Shift+클릭: 앵커부터 범위 선택(Cmd+Shift는 선택에 추가). 이 둘은 열려 있는 diff를 바꾸지 않습니다.
- 행 우클릭: 선택 안의 행이면 선택 전체, 아니면 그 행 하나를 대상으로 메뉴(`Discard` 또는 `Discard N files`)가 뜹니다. 메뉴에서 Enter 또는 클릭하면 확인 창이 뜨고, `Discard`를 확인하면 파일별로 변경을 되돌립니다(신규 파일은 삭제). 충돌(U) 상태 파일은 건너뛰고 결과를 패널에 알립니다. Esc는 메뉴·확인 창을 닫습니다.
- 메시지 입력란에서 Esc: 입력 포커스를 빠져나옵니다.

## 구조

같은 mod가 자기 자신을 오버레이로 다시 엽니다. 레이아웃에서 props 없이 뜨면 패널이고, `props.mode`가 `"menu"`(우클릭 팝업) 또는 `"confirm"`(확인 대화상자)이면 `menu.js`의 화면을 그립니다. 확인하면 `shared("git-changes.discard")`에 요청을 쓰고, 패널 인스턴스가 이를 읽어 git을 실행합니다. 순수 로직은 `logic.js`에 있습니다.

## 원본

herdr 내장 `changes` mod(0.1.15)를 복제해 수정한 파생물입니다(Apache License 2.0, 루트의 `NOTICE` 참고). 다중 선택, 다중 파일 Discard, 우클릭 메뉴(`menu.js`)가 이 저장소에서 추가한 부분입니다.

## 의존

- `git` 명령이 필요합니다.
- 옆 패널 레이아웃(`layouts/*/my-main.json`의 `panel-body` 스택)에 들어가 있어야 하고, 탭 바의 `Changes` 버튼은 `mods/tabs-graph`가 그립니다.
